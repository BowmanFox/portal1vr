# README image sources

The screenshots were captured locally while playing Portal 1 VR fullscreen with a Pico headset through SteamVR on September 14, 2026. SteamVR's `IVRScreenshots::TakeStereoScreenshot` captured the live headset view while Portal was the active scene. The single-eye preview images were compressed losslessly, with their pixels verified unchanged. No stock gameplay screenshots are used.

| Repository file | Source |
| --- | --- |
| `logo.png` | [Original Portal logo from Steam](https://cdn.akamai.steamstatic.com/steam/apps/400/logo.png), unchanged |
| `screenshots/portal1vr-playtest-1.png` | Local Portal 1 VR playtest, test chamber 03 at 00:16:30 Central |
| `screenshots/portal1vr-playtest-2.png` | Local Portal 1 VR playtest, elevator at 00:16:38 Central |
| `screenshots/portal1vr-playtest-3.png` | Fresh local Pico Portal 1 VR playtest, captured at 01:20 Central |

Portal branding and game artwork belong to Valve. The playtest used the mod code at commit `1c1cfb336b878fc222911f20f2a85d215f4d7c9d`.
